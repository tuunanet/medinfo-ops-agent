# Specs

All planning documents for `medinfo-ops-agent` live here.

## Sources of truth

- `planning-context.yaml` contains confirmed elaboration decisions.
- `state.yaml` contains current workflow state and the next-skill handoff.
- `release-plan.yaml` indexes planned epics after release planning.
- `execution-status.yaml` owns epic and story completion status.
- `product/` contains vision, scope, and domain language.
- `tech-architecture/` contains architecture and quality plans.
- `epics/` contains story specifications and runnable tasks.
- `verifications/` contains test, review, and evaluation evidence.
